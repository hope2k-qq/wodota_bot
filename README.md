# WoDOTA — авто-игра

Бот для кастомки [WoDOTA](https://steamcommunity.com/sharedfiles/filedetails/?id=2880603428)
в Dota 2. Сам заходит в игру, берёт героя, качает способности и таланты,
покупает предметы, отбивает волны и боссов, после матча начинает
заново. Сколько матчей подряд — не ограничено.

Управляется с телефона: страница пульта включает и выключает бота,
показывает лог и снимок экрана и правит все настройки.

Эта страница — **как этим пользоваться**. Как оно устроено внутри и что
именно умеет — в [FUNCTIONS.md](FUNCTIONS.md).

---

## Установка на чистом ПК

**1. Python.** Скачать с [python.org](https://www.python.org/downloads/)
(подойдёт 3.10 и новее) и при установке **обязательно отметить галочку
«Add python.exe to PATH»**.

**2. Проект.** Скачать папку с GitHub и распаковать куда угодно, например
в `C:\wodota_autoplay`.

**3. Запустить `WoDOTA.cmd`** двойным кликом. Он сам найдёт Python,
доставит недостающую библиотеку Pillow и поднимет пульт. Адрес пульта
появится в окне — его и открывать с телефона.

Ставить что-то вручную не нужно. Если всё-таки хочется:

```powershell
cd C:\wodota_autoplay
```

```powershell
py -m pip install -r requirements.txt
```

Именно так, **из папки проекта**: `requirements.txt` лежит в ней, и из
`C:\Windows\system32` его не видно.

**4. Dota.** Параметры запуска:

```
+fps_max 0 -console -gamestateintegration
```

Режим экрана — **окно без рамки**. В полный экран Dota меняет разрешение
рабочего стола, и снятые координаты уезжают в чужой профиль.

**5. Конфиг GSI.** Через него игра рассказывает боту всё: волны, золото,
инвентарь, уровень. Класть руками не надо — бот сам положит файл при
первом запуске и скажет, что **Dota надо перезапустить**: она читает эту
папку только при старте.

Если захочется руками, файл лежит в `data\gamestate_integration_wodota.cfg`,
а класть его сюда:

```
Steam\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\
```

**6. Свой билд.** В поставке лежит только образец `standard`. На пульте:
**Настройки → Герои → Новый билд**, выбрать героя — план талантов
соберётся сам. Останется снять точку пика кнопкой на странице билда.

**7. Экран.** Готовы профили 2560×1440 и 1920×1080. Другое разрешение —
скопируй ближайший файл из `screens\` под своё имя `ШИРИНАxВЫСОТА.json`
и сними координаты на пульте.

Конфиг GSI бот кладёт сам и напоминает, что игру надо перезапустить;
о несня́той точке пика тоже скажет при запуске.

### Что необязательно

- **Пароли и id напарника** (`settings\local.json`) нужны только для игры
  вдвоём. Пароль пульта и пароль пати бот придумает сам при первом
  запуске.
- **cloudflared** нужен, только чтобы открывать пульт из другой сети. Без
  него всё работает дома, а в окне будет строчка «туннель не поднят».
  Нужен адрес снаружи — поставь:

  ```powershell
  winget install Cloudflare.cloudflared
  ```

  Не нужен вовсе — впиши `null` в `remote.tunnel`, и бот о нём не
  вспомнит.

## Запуск

### Через exe

Собирается один раз, дальше запускается двойным кликом и без Python:

```powershell
py -m pip install pyinstaller
```

```powershell
py app\build_exe.py
```

В корне проекта появится `WoDOTA.exe`. **Запускать его надо оттуда же** —
настройки, билды и координаты он берёт из соседних папок, а не из себя,
поэтому их можно и дальше править с пульта.

```
WoDOTA.exe                 пульт, бот выключен
WoDOTA.exe --run           пульт и сразу бот
WoDOTA.exe --bot           только бот, без пульта
WoDOTA.exe --bot --check   проверки бота
```

### Без сборки

`WoDOTA.cmd` — то же самое двойным кликом. Он сам найдёт Python, доставит
Pillow, если её нет, и поднимет пульт.

Или руками:

```powershell
py app\remote.py
```

Поднимает пульт. **Бот при этом выключен**, его включает кнопка в шапке
страницы. В консоль печатается адрес с паролем — его и открывать с
телефона; внешний адрес сразу кладётся в буфер обмена.

```powershell
py app\remote.py --run
```

Пульт и сразу бот.

```powershell
py app\bot.py
```

Только бот, без пульта. `py app\bot.py 3` — ровно три матча и выход. Перед
стартом отсчёт пять секунд, чтобы переключиться в Dota.

**F12 — аварийный стоп в любой момент.**

## Обновить на другом ПК

Настройки и билды лежат вне гита, поэтому обновление их не трогает:

```powershell
cd C:\wodota_autoplay
```

```powershell
git pull
```

Всё личное остаётся на месте: `settings\local.json`, `logs\`, свои билды в
`heroes\`. В них лежат и пароли, и выбор героя, и любая правка настроек с
пульта.

Если качал файлы руками и гита в папке нет — один раз склонировать заново
рядом, а `settings\local.json`, `heroes\*.json` и `logs\` перенести в новую
папку.

Если `git pull` ругается на изменённые файлы — значит правили что-то из
поставки руками. Посмотреть что:

```powershell
git status --short
```

Вернуть как в гите (свои настройки при этом не пострадают, они в других
файлах):

```powershell
git checkout -- .
```

## Пульт

Пять вкладок внизу, состояние бота и кнопка **Запустить / Выключить** —
сверху, на любой вкладке.

### Автоигра

Снимок экрана, перезапуск бота и хвост лога, который дописывается сам.

### Настройки

| что | зачем |
|---|---|
| Режим | один герой или обход всех |
| Вдвоём | соло или игра в пати со вторым ПК |
| Игра и компьютер | сборка Dota, обновления, перезапуск игры, выключение ПК |
| Функции закупа | что делают роли предметов и на какой они клавише |
| Общие настройки | весь `config.json` с пояснениями к каждому полю |
| Координаты экрана | точки профиля: снимаются кнопкой, см. ниже |
| Сложность | десять карточек арены |
| Герои | список билдов, звезда и фильтр избранных |

### Билд

Всё, что бот делает за этого героя: выключатели функций, закуп списком,
точка пика, план талантов, способности и реакции. Поля подписаны
по-человечески, без путей из JSON.

### Статистика и логи

Сводка по прогонам и таблица матчей; логи — хвост последних сотен
килобайт со ссылкой на весь файл.

## Повседневное

### Снять координату

На страницах **Координаты экрана** и **Билд → Точка пика** у каждой точки
кнопка **«Снять координату»**:

1. нажал на телефоне;
2. навёл мышь на нужное место в игре;
3. через пять секунд бот подсмотрел курсор.

Точка пересчитывается во все профили экрана и записывается сразу —
«Сохранить» для неё не нужно. Снимать надо **с игрой на экране**: профиль
выбирается по текущему разрешению.

### Выбрать билд

Настройки → Герои → нажать на билд. Применится со следующего матча,
начатый доигрывается как был.

**Звезда** слева от билда кладёт его в избранное, квадратик над списком
сжимает список до избранных. Выбор запоминается.

### Разложить таланты

Билд → **Разложить таланты по сетке**. Три дерева, как в игре: клик по
ячейке добавляет ранг в конец плана, клик по шагу делает его точкой
вставки, крестик убирает. Сверху видно, проходит ли план по правилам
аддона и какой шаг их нарушает.

### Новый билд

Настройки → Герои → **Новый билд**: выбрать героя, имя файла и основу.
План талантов соберётся под выбранного героя сам. Останется снять точку
пика.

### Убрать билд

Билд → внизу страницы **Удалить билд**. Файл не пропадает: он
переезжает в `logsemoved`, оттуда его можно вернуть обратно в
`heroes`. Образец `standard` удалить нельзя — из него делаются новые.

### Настройки самой Dota

Автоатаку бот настраивает сам: в начале каждого матча он отправляет в
консоль команды из **Настройки → Общие настройки → Команды в консоль при
старте матча**. По умолчанию там режим «всегда» и запрет приказам
переключать автоатаку. Бинд на клавишу для этого не нужен.

Слежение камеры за героем снять нельзя: его включает сама аркада со
стороны сервера, а не настройки Dota. Сбрасывается оно только выбором
героя, поэтому бот жмёт эту клавишу там, где камера и цепляется: на
первой волне матча и на первой волне после каждого босса. Повод он берёт
от самого босса, а не от номера волны — счётчик волн иногда сбивается.

### Способность по кулдауну

Билд → выключатель **Способность по кулдауну** (по умолчанию выключен) →
ниже, в разделе с тем же названием: какая способность, через сколько секунд
после выхода крипов первое нажатие, откат, сколько нажатий за волну и нужен
ли клик после клавиши. Откат бот считает по этому числу — игра своих
откатов не присылает, так что ставь с небольшим запасом.

### Играть вдвоём

Настройки → **Вдвоём** → Пати. На втором ПК — копия проекта с
`party.role` = `second` и тем же паролем пати. Подробности —
[FUNCTIONS.md](FUNCTIONS.md#игра-в-пати).

Один никогда не играет: если собраться не вышло, оба выходят в меню и
заходят в кастомку заново, пока не соберутся (`party.solo_never`). После
матча оба тоже выходят в меню и ждут там друг друга
(`party.menu_sync_s`), чтобы заходить одновременно, а не по своим часам. Тот,
кто сдался первым, говорит об этом второму, чтобы тот не досиживал своё
ожидание впустую. Выключается через `party.solo_never: false`.

Правку надо поставить **на оба ПК**: если на одном останется старая
версия, он уйдёт в матч один, и они снова разъедутся.

## Если что-то не так

**Бот стоит на первом экране и ничего не нажимает.**
Скорее всего нет данных GSI. В логе будет сказано прямо: конфиг положен на
место — перезапусти Dota; или файла нет вовсе.

**GSI не работает, хотя файл на месте и параметры запуска стоят.**

Частые причины:

- **Dota не перезапускалась** после того, как файл появился: эту папку
  она читает только при старте.
- **Параметры запуска стоят у другой учётки Steam.** Нужны у той, под
  которой запускается игра.
- **Игра запущена ярлыком на `dota2.exe`**, а не через Steam — тогда
  параметры не применяются вовсе.
- **Dota стоит в другой библиотеке Steam** (на другом диске), а файл
  положен в основную. Бот ищет игру по всем библиотекам и пишет в лог
  ту папку, в которую кладёт.
- **Порт 3100 занят** — обычно потому, что бот уже запущен в другом окне.

**Пульт не открывается, порт занят.**
Либо он уже запущен, либо остался висеть прошлый. Закрой процесс Python
или смени `remote.port`.

**Бот долго ждёт кнопку в лобби.**
Между матчами он держит паузу 30 секунд (`watchdog.between_matches_s`), не
трогает экран, пока тот не прорисуется, и после этого ждёт ещё три секунды
(`launch.screen_settle_s`) — интерфейс дорисовывается позже, чем игра
начинает слать данные. Если экран уже пройден, бот это видит по состоянию
игры и идёт дальше, не выжидая две минуты. Лобби, поиск и сложность он
различает только по картинке на экране: для игры это одно и то же
состояние, так что по нему ориентироваться нельзя. Экран сложности бот
ждёт до трёх минут — поиск бывает долгим — и узнаёт по золотой кнопке
подтверждения. Если ждать всё равно приходится — добавь секунд в паузу.

**Первая игра проходит нормально, следующие — нет.**
Так было, пока бот после матча оставался в аркаде: она считала прошлый
матч незаконченным и показывала «у вас уже есть активная игра» вместо
выбора режима. Теперь после каждого матча бот выходит в главное меню и
заходит в кастомку заново — так же, как при первом запуске
(`launch.menu_wait_s` — сколько ждать меню).

**После вылета игра предлагает вернуться в старую игру.**
Бот всегда из неё выходит: жмёт «покинуть игру», подтверждает в окне и
заходит в новую. Ждать нельзя — панель сама вернула бы его в ту игру
через полминуты. Узнаёт он её по двум кнопкам сразу, красной и зелёной,
и смотрит на экран с первой секунды захода, не дожидаясь данных от игры. Для этого в профиле экрана есть три точки
(`leave_game`, `leave_back`, `leave_confirm`); для 2560x1440 и 1920x1080
они уже проставлены, для другого разрешения снимаются на пульте.

**Бот долго стоит на выборе героя.**
Экран выбора героя бот узнаёт по золотой монете в верхней полосе
(точка `hero_screen` в профиле экрана) и жмёт сразу, как её увидит.
Для 2560x1440 и 1920x1080 точка уже проставлена; для другого разрешения
снимается на пульте. Если точки нет, бот вернётся к медленному способу —
будет ждать, пока прорисуется сетка героев.

**Бот не выбрал сложность, играет на той, что стояла.**
Значит, он не узнал золотую кнопку подтверждения на экране сложности.
Наугад он не жмёт. Пересними на пульте точку этой кнопки
(Настройки → Координаты экрана → Снять координату) с открытым экраном
сложности.

**Карточка сложности выбрана, но не подтверждена.**
Кнопка подтверждения оживает не сразу после выбора карточки. Бот ждёт
`launch.confirm_wait_s` (по умолчанию 1.2 секунды) и потом проверяет, что
экран ушёл; не ушёл — повторяет весь шаг. Если на твоей машине окно
отзывается медленнее, добавь этой паузе времени.

**Попал в игру к незнакомцам.**
Бот считает героев на карте: лишний герой — чужая игра. Тогда он выходит в
меню сразу, напарнику сообщает то же самое, и оба ждут 15 минут
(`watchdog.strangers_wait_s`), чтобы не попасть обратно в ту же компанию.
Смотрит он только в начале матча, когда герои уже выбраны и пошла первая
волна: состав за матч не меняется. Выключается через
`watchdog.alone_only`.

**В игре выдало не того героя.**
Бот выходит в меню и заходит заново (`watchdog.wrong_hero_leave`): чаще
всего это чужая игра, где героя выдали случайно. Если герой не тот из-за
настроек билда, выключи эту настройку — тогда бот доигрывает матч, но
таланты не берёт.

**Раунд не кончается, бот стоит в матче.**
Если волна идёт дольше пяти минут (`waves.max_wave_s`), бот выходит в меню
и заходит заново: изнутри такой раунд не поднять.

**Бот сам останавливается.**
Смотри последнюю строку лога: замолчал GSI, не удалось зайти в кастомку,
зависло лобби. Пульт поднимает бота заново сам и считает перезапуски.
Пропавшее окно Dota он теперь чинит сам — поднимает игру через Steam.

Всё, что он делает, пишется в `logs\bot.log` — туда и смотреть в первую
очередь.
